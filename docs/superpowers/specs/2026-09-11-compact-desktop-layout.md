# 紧凑桌面比例

用户反馈整个桌面界面偏大，要求接近 Codex 的比例。本次在现有分支调整逻辑尺寸与界面密度；没有可测量的 Codex 完整窗口截图，因此不声称像素级一致。

- 默认窗口从 1440×920 改为居中的 1100×680，最小窗口从 1120×720 改为 900×560。
- 全局默认字号为 13px；已有明确字号的代码、证据和辅助文本不做整体缩放。继续使用 Windows 的 DPI 缩放，不使用 CSS zoom 或 transform 缩放整个页面。
- 左侧栏 220px、右侧栏 320px、工作区标题栏 52px；1050px 以下右侧栏继续以覆盖层展示，顶部与标题栏对齐。
- 收紧输入区、菜单、项目主页和设置页的字号、间距及控件高度。短窗口保留滚动访问。
- 不改变 Agent、执行环境、审批、持久化或数据传输行为。

新增默认/最小窗口尺寸回归测试。验收命令：`cargo test --workspace`、`npm test`、`npm run build`、`npm run build:desktop`。手工检查 1100×680 和 900×560 的主界面、菜单、设置滚动及 Windows 125%/150% 显示缩放；未实际执行的 DPI/安装检查不得视为通过。

实际验证：Rust workspace 测试通过；前端 167 项测试及浏览器扩展 22 项测试通过；Web 生产构建通过。浏览器预览检查了 1100×680 主界面、900×560 侧栏菜单和设置页，菜单及设置可通过 Escape 关闭。真实 Windows 125%/150% DPI、安装及真实模型/SSH 验收未执行。

`npm run build:desktop` 已通过，生成 x64 NSIS 安装程序及桌面 EXE；构建只有前端 chunk 大小提示和 MSVC 链接器信息警告。
