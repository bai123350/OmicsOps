## 行为

- 一个顶层执行过程折叠区包含按事件顺序排列的公开 PROGRESS 与工具调用。
  活动过程默认展开，已完成/历史过程默认折叠；最终回答独立保留。
- 工具名称、主题、状态、耗时、结果行数保持真实；每个调用可独立展开。
  输入使用脱敏且格式化的完整 JSON，JSON 结果格式化后以独立限高滚动块显示，行数与展示文本一致；原事件不改写。其他结果以独立限高滚动块显示；失败默认展开。
  Skill 调用带 SKILL 标记与技能主题。
- 移除运行中指导卡片与六阶段轨迹/任务快照面板；不删除已有事件或改写冻结协议。
- 待审批、提问和恢复卡片位于折叠区之外。已决定的审批不再重复展示；
  已回答问题显示提交状态和回答。原有授权、恢复及不确定派发操作不变。
- 只展示公开模型输出，不把内部推理字段或参考截图中的思考文字注入界面。
