# 普通 Agent 的按风险运行时审批

普通 Agent 选择「帮我批准」（RiskBased）时，宿主对每条 `runtime.execute` 调用独立判断。常规 Python/R 计算、公开 HTTP GET 和项目相对路径的结果写入可直接执行；词法规则识别到进程或 shell 调用、安装、动态执行或反射、凭据或环境变量访问、常见 HTTP 写请求、删除或重命名、明显的项目外或控制目录路径、独立后台作业，以及不支持的语言或无法完成词法切分的代码时要求逐次审批。判断在桌面宿主的 `ToolExecutorV4::risk_based_target_approved` 完成，不依赖模型自报风险，也不沿用本轮较早调用的批准。

该词法判断是减轻常规科研操作审批负担的尽力而为规则，不是 Python/R 沙箱、代码安全证明或数据驻留保证。动态绑定、第三方库的内部行为以及运行时拼接的路径无法由词法规则证明安全。运行时仍执行既有的冻结能力、参数与路径检查；模型、MCP 和外部服务仍可能接收提示词、结果或元数据。`RequestApproval` 继续逐次询问，`FullAccess` 保持既有计算权限；浏览器和 MCP 使用各自授权门禁。已记录的单次审批继续按原调用、运行、范围和 hash 绑定恢复，已拒绝的调用不得因新规则转为直接执行。SSH 与本地使用同一判断；远端作业的派发、查询和恢复语义不变。

确定性测试覆盖 Local/SSH 首次常规调用、危险后续调用、旧批准和拒绝事件、Plan 范围隔离、桌面执行器接线、公开 Europe PMC GET 与项目内 TSV/JSON/Markdown 写入，以及别名、进程、外部路径、HTTP 写请求、动态执行、R 危险调用和无法词法识别的输入。手工 smoke：在本地及 SSH 可用的临时项目中选「帮我批准」，运行公开文献 GET 和 `results/literature/` 下结果写入，确认无审批卡；随后提交 shell、删除及项目外写入并确认逐条暂停。再分别确认「每次请求批准」和「完全访问」，以及浏览器/MCP 审批保持原语义。真实模型、SSH 和研究工作流验收须按 `acceptance/README.md` 使用一次性环境；自动化测试不能替代这些验收。
