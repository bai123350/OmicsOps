# Wisp 风格首页改造

日期：2026-09-22

## 已确认的目标

用户选择参照 Wisp Science 的整体布局与视觉风格改造 OmicsOps 首页，并保留现有功能。架构评估使用 GPT-6 ultra，代码实现使用 GPT-5.6 Sol ultra。

此次改造让首页更便于继续科研项目和选择研究模板：合并分散的品牌与介绍区域，减少大卡片和空白占用，并保持本地存储与计算位置可辨认。

## 参考与适配

参考公开源码：

- [Wisp ProjectsScreen](https://github.com/xuzhougeng/wisp-science/blob/main/ui/src/app_support/projects.rs)
- [Wisp 首页样式](https://github.com/xuzhougeng/wisp-science/blob/main/ui/src/styles/projects.css)

Wisp 首页在内容顶部整合品牌、简介和操作，下方为“项目 / 最近会话”两栏，使用紧凑列表、淡边框、小圆角和弱阴影。OmicsOps 借鉴这一版式，将两栏适配为“最近项目 / 创建新项目”，右栏沿用四个已有模板；不引入最近会话聚合、研究日历、全局收藏库、导入或临时会话等参考产品功能。

## 页面设计

- 顶部整合 OmicsOps 品牌、简短科研工作台说明，以及现有搜索、语言切换和设置操作；删除重复的大标题介绍区。
- 主体采用有最大宽度的两栏布局。左栏按现有顺序展示项目，右栏纵向展示单细胞 RNA 测序、Bulk RNA 测序、文献综述和空白研究项目模板。
- 项目行保留名称、本地目录、计算位置及独立删除按钮；无项目时提供简洁的空状态。模板保留名称和描述，点击后进入原有创建对话框。
- 采用浅中性色、淡边框和现有 OmicsOps 强调色。优先使用主题语义变量，兼容浅色、深色和界面缩放；窄窗口切换为单栏，长目录和远端地址不得撑破布局。

## 修改范围与架构边界

主要修改 `src/features/projects/ProjectLibrary.tsx`、`project-library.css` 及相关测试；按需调整 `src/desktop-layout.css` 和 `src/appearance.css` 中影响首页的样式。只有首页文案或可访问名称改变时，才同步 `src/DesktopApp.test.tsx` 的对应断言。

`ProjectLibrary` 继续接收现有项目、连接与回调。`DesktopApp` 继续负责项目创建、打开、删除及全局设置、搜索组合。此次不新增后端命令、DTO、持久化结构、外部依赖或启动路由行为；启动自动选择已有项目的逻辑保持不变。

保留以下行为边界：

- 创建时仍必须选择本地目录，沿用可信主机指纹筛选、默认计算位置、远端绝对路径校验、取消和错误处理。
- 首页展示已保存的计算位置；已配置连接不代表当前在线、依赖齐备或计算就绪。有远端绑定但找不到连接记录时，不得将项目标成仅本地。
- 删除沿用现有确认与失败处理；项目打开和删除按钮保持同级，删除不触发打开。删除记录与保留本地、远端文件的语义不变。
- 所有可关闭叠层沿用窗口级 Escape 栈，按视觉层级一次关闭最顶层。
- 凭据存储、主机信任、宿主审批、执行隔离、数据传输和远端作业恢复语义不变；首页不新增就绪保证或“所有数据永不离开本机”的承诺。
- 不修改本次工作开始前已有的 Agent 上下文、WorkspaceShell 或其他未提交改动。
