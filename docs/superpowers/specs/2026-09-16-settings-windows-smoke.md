## 准备与记录

使用Windows上的真实Tauri宿主，记录commit、Windows版本、运行方式（开发可执行程序/本地desktop构建）、窗口尺寸、系统缩放及应用缩放。本地构建不等于已发布安装包，不创建Release或分发包。关闭生产项目，创建两个一次性本地项目A/B和会话A1/A2/B1，目录与名称明显不同；仅放几份小文本，不使用科研样本、真实密钥或真实SSH主机。清理只针对本轮明确创建的项目/文件/凭据，不删除整个应用数据目录。

每项记录：`日期 | commit | 编号 | 通过/失败/未执行/待实现 | 实际操作与观察 | 截图或脱敏日志 | 限制`。失败记录复现，不用其他测试结果覆盖。证据分四类：

| 类别 | 可证明的范围 |
|---|---|
| 确定性检查 | 记录实际 `cargo test --workspace`、`npm test`、`npm run build`；桌面组合/依赖变更加 `npm run build:desktop`，依赖锁变更加 `npm ci`。本清单不替代这些检查；Vitest子阶段通过不等于整条npm命令成功。 |
| mock UI | Vite/Edge + 模拟Tauri响应可验证页面、键盘、布局、草稿和调用参数；不能证明keyring、文件操作、OS通知或真实统计。 |
| 原生smoke | 真实Tauri命令、临时项目/文件、测试keyring、真实OS通知；运行/权限/用量记录若由受控fixture产生，明确记录fixture来源，不能称真实Agent计算。 |
| 模型/SSH验收 | 按 `acceptance/README.md` 单独执行并记录ignored测试；真实付费模型、SSH/SLURM/PBMC不是基础smoke前提，未执行就标未执行。 |

## 窗口、隔离与草稿

- [ ] W1：以720×600窗口、应用120%缩放，显式dark且Windows为light，逐页打开下面20行；检查标题、末项、错误区、按钮可达，主区能滚到底，页面和卡片不横溢。再以1440×1000复查长列表，并切light/system验证跟随语义。记录实际缩放，不把CSS尺寸当物理屏幕尺寸。
- [ ] W2：打开设置立即在window按Escape，无需先聚焦内容，设置关闭；再打开详情→确认，逐次按Escape只关最顶层。覆盖Credentials编辑/删除、Skills详情/删除、Plugins预览/确认、Browser撤销以及已有选择器；尚未实现的层保留待验收。
- [ ] W3：A1输入唯一草稿，打开/关闭设置及切页后草稿仍在。项目作用域页面在A/B来回切换，不能呈现/保存到旧项目；延迟操作结果不能把B拉回A。全局凭据/模型/Skills不会伪装成项目隔离；检查提示的实际作用域。会话切换时不把A1草稿插入A2，重启恢复仅按现有已保存偏好验证。

## 凭据与原生通知专项

- [ ] C1：只创建明确命名的 `settings-smoke-<日期>` 自定义测试凭据，值用无权限随机测试串。创建后列表只展示非秘密引用/状态；重开仍可见。替换时输入新测试串，任何响应/日志/截图不出现旧值；不截图正在输入的新值。
- [ ] C2：通过现有配置UI给测试模型/MCP绑定该引用，尝试删除应报告仍被引用；解绑后未引用删除成功。若UI不支持该类型绑定，用项目现有测试覆盖并记录未做原生绑定，不通过直接改SQLite绕过宿主。SSH类型用fixture格式校验，不放真实私钥。
- [ ] C3：清理本轮测试配置与自建keyring条目；Windows凭据管理器确认仅该测试条目移除，不批量清理其他账户。
- [ ] N1（原生手工验收未执行）：General默认通知关闭；读取权限状态不弹请求。用户开启/点测试后，真实Windows权限/通知设置允许时出现标明测试的通知；关闭/拒绝时不伪称已送达。分别记录应用偏好、OS权限、专注助手及实际可见结果。
- [ ] N2（原生手工验收未执行）：使用既有受控native事件测试fixture，或可用且无需外网的本地真实运行，创建新的完成/失败/需处理live事件，窗口后台时只显示固定通用通知，前台抑制；重复同event hash只一次。不要为此新增生产“任意通知”接口、改生产DB或调用付费模型。无可执行live来源时标未执行，保留native sink确定性测试证据，不将测试按钮当live桥接通过。
- [ ] N3：重开历史会话/重启水合不得重放旧通知；关闭偏好后新事件不发。OS发送失败反馈可见，不自动重复相同事件；开发可执行程序与本地安装环境分别记录，未验证平台不作保证。

## Skills与Plugins临时夹具

在独立临时来源目录写UTF-8 `SKILL.md`：frontmatter `name: settings-smoke-skill`，正文一行普通测试说明；另放 `notes.txt`、超过256KiB的文本、`token.txt`（仅虚构测试串）。保留原始来源目录用于确认导入是复制；SHA由现有安装器/预览产生，不手改catalog。

- [ ] S1：导入后详情显示实际来源和受管安装，重复导入同SHA不产生错误所有权；安全正文能读，token.txt不得预览，超限文本不可读。修改受管副本后应报告changed且拒绝按旧SHA预览/物理删除；不要修改捆绑技能做测试。
- [ ] S2：自有未改包可物理删除且原始来源保留；legacy/external只从库移除并明确保留文件；bundled禁止删，plugin-owned转Plugins。链接/共享根/摘要变化/有效依赖/其他项目active或可恢复run应阻塞；危险夹具优先依确定性临时目录测试，不在真实应用库手造junction。没有对应原生fixture的保护项标未执行。
- [ ] S3：删除确认立即Escape只关确认；占用文件失败不伪称全删，未完operation可见，释放占用后按operation重试；库已移除但文件未清理须分别显示。历史冻结文本不被删，未发送skill引用失效有反馈，不自动换同名版本或删草稿。

Plugins格式以[已批准计划](../plans/2026-09-15-plugins-general-settings.md)为准。准备独立SKILL.md，无附件/脚本/外部链接；PowerShell `Get-FileHash -Algorithm SHA256`计算该文件实际字节摘要，填入 `omicsops-plugin.json`：schema_version=1、id=`lab.settings-smoke`、version=`1.0.0`、name为测试名称、skills含相对SKILL.md路径及小写sha256，mcp_presets为空数组。不要用占位摘要安装。

- [ ] L1：选本地包→预览→安装，真实贡献出现在Skills且初始禁用；重复相同包幂等。错误SHA/未知字段/越界路径包应拒绝且库不变；包安装不执行代码。
- [ ] L2：启用后贡献可被现有选择器发现，停用后不能被direct引用或依赖偷偷带回。修改源正文、重算摘要、version改1.0.1，用明确更新动作查看差异再更新；新版需显式启用，旧冻结记录不变；损坏更新应保留旧版。
- [ ] L3：移除仅处理本包实际拥有的受管贡献和文件，外部源/共享项保留；bundled或其他包贡献不受影响。失败状态可见且可恢复；重启后按已记录operation恢复，不扫描/删除任意目录。完成后清理本轮包和测试来源。
