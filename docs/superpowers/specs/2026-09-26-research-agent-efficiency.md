# 文献调研 Agent 的重复工作与目录读取优化

用户反馈：miRNA 文献调研出现多轮规划、反复调用工具。本次针对现有普通 Agent 回路做限定修复，保持宿主审批、原始证据和冻结执行范围。

## 定位依据

对本机应用数据库使用 SQLite `mode=ro`、`query_only` 查询，仅统计最近相关运行的事件元数据；未导出研究提示词、路径、文件正文、凭据或完整事件。

最近一条相关记录含 100 次模型请求、96 个已完成工具批次。其中 `artifact.verify` 调用 100 次，但仅有 5 种不同的稳定观察；`project.read` 调用 90 次，同样只有 5 种；`project.list` 调用 47 次，仅有 3 种。最后 55 个批次没有新增稳定观察。事件时间跨度约 156 分钟，其中可包含等待、审批或重试，不能当作纯模型计算耗时。

该记录的 MCP 目录包含 247 个工具，结果正文为 291,627 UTF-8 字节；随后出现 33 次 `agent.read_tool_result`。目录中的完整 schemas 被放在通用首尾截断视图里，寻找中间工具需要读取大量无关 schema。调用次数是历史观测，不等于所有翻页均无价值。

对签名进行内存重放时，现有“有序批次完全重复后缀”判断未触发。仅变更批次顺序、分组或子集即可掩盖重复观察。采用最近 32 个已完成观察单元的候选判断，在该历史序列第 46 个批次、已见 49 次模型请求时触发；这是诊断原型的重放结果，不是优化后真实调研耗时或成功率测量。

已排除的解释：普通请求没有强制额外 Planner 模型调用；分类和任务清单可选；同批独立工具已并发派发；MCP 目录在同一 run 内已有复用。没有据此改路由、关闭审查或增加并发副作用。

## 实施范围

1. 在现有无进展判断中增加有界的新观察判断。连续达到现有阈值的完整批次没有新观察时停止下一次模型与工具派发。参数、实际内容、校验和和作业状态继续参与判断；新用户指导或科学状态变化重置判断。停止仍为需要调整的状态，不是研究完成。
2. MCP 目录的模型视图采用精简目录；现有 `agent.read_tool_result` 增加定向目录/工具选择，从已签名的原始目录读取指定 schema。保留原有身份校验、分页预算和无 selector 的兼容行为，不重新检索 MCP，不修改完整原始事件或审批绑定。

不缓存或跳过实际文件核验，不设 miRNA 专用关键词分支，不降低证据标准，不延长超时，不迁移数据库或重写调度系统。

## 验证记录

### 确定性回归

- 无进展保护：变换工具顺序、批次分组和子集，且内容不变时达到阈值即停止，停止后不会再调用模型。实际内容、分页位置或状态变化仍可继续，未关闭批次不计数。底层与 Agent 集成回归均先观察失败，再通过；实现提交 `c566d60`。
- MCP 目录：合成 247 个工具，原始 `data` 为 291,044 字节。完整原文分页需要 40 页，完整精简目录需要 7 页；已知中间工具身份后，完整 schema 可用 1 次定向读取取得。初始目录事件投影为 4,992 字节。这里的 1 次不包含发现目录或寻找工具身份所需的页面。
- 模拟模型回路：首次目录页中可见的工具身份 → 定向读取完整 schema → 宿主绑定原始目录 hash 后调用工具 → 引用实际工具结果事件完成，共 4 次模型请求。这是可复现的测试替身流程，不是对真实模型行为、论文质量或调研速度的承诺。
- 覆盖完整名称保留、服务筛选、UTF-8 与转义后字节预算、大 schema 分页、未知/重复身份、错误 hash/字段/事件范围，以及未使用 selector 时的原文兼容读取。Plan 仍不暴露结果读取工具。
- 复核确认内置工具描述不参与当前冻结 RunSpec 的 hash；本次不迁移或修改冻结计划，MCP 审批绑定继续取自完整持久事件。
