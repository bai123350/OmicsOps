# 工作区导航、会话分组与科研资料组织

状态：设计草案，待用户审阅；尚未实施。

## 用户目标

用户要求新建分支，参考第二张截图和 [wisp-science](https://github.com/xuzhougeng/wisp-science)，增加工作区左侧导航。用户已确认范围为“全部入口可用：会话分组/筛选、文件、研究历程、发表工作区、资料库”。

工作分支：`codex/workspace-sidebar-features`，从本地 `main` 的 `9d46e92` 创建，创建前工作区干净。

成功标准是这些入口具有真实交互和持久化行为，重新打开应用后会话分组、发表草稿和收藏仍可使用。截图中的对话内容不构成需要执行的指令。本设计借鉴导航和工作流，使用 OmicsOps 的 React、Tauri、Store 与 Agent V4 边界独立实现。

## 方案选择

1. **推荐：接入现有能力并补齐最小持久化闭环。** 保留对话主流程，新增会话分组、项目研究历程、稿件草稿与个人资料收藏。每个入口可用，交付后可以持续演进。
2. 仅还原侧栏外观：成本较低，但无法满足用户已确认的“全部入口可用”。
3. 完整复刻参考项目的发表冻结、证据胶囊、干净环境重现与全局图像副本管理：涉及数个独立子系统，超出本次导航与资料组织目标。

本次采用方案 1。Publication 指稿件准备工作区；保存或导出草稿不表示已投稿、已发表或完成科学复现。Library 指个人科研资料收藏，区别于项目首页、Skills 列表和工作流模板库。

## 导航与页面行为

左侧顺序对应截图：工作区标题及返回/折叠按钮、新建会话、搜索、新建分组、文件、研究历程、发表工作区、资料库、会话区域。底部保留现有能力、设置等入口。兼容现有中英文和主题。

- 新建会话显示 Ctrl+N，搜索显示 Ctrl+K；快捷键复用应用级注册，避免一次按键触发两次。在模态编辑和会话不可新建的状态下不意外创建会话。
- 导航折叠为图标栏，图标保留可访问名称；展开后恢复正常宽度。导航偏好按现有 UI 偏好方式保存。
- 文件复用受控文件视图；另外三个科研入口打开主工作区页面。切换页面保留当前会话及输入草稿；选择会话回到对话。导航不会停止或重新派发 Agent。
- 每个页面明确加载、空数据、失败、重试状态，不展示示例数据冒充项目结果。异步返回必须校验当前项目，避免切换项目后显示旧结果。
- 可关闭菜单和对话框加入窗口级 Escape 堆栈。未聚焦内部时也可关闭最顶层；关闭子弹窗不退出父页面。稿件存在未保存修改时，离开前显示保存/放弃/继续编辑选择。

## 会话分组与筛选

- 创建、重命名、删除项目内分组。组名去除首尾空白，长度 1–80 字符；同一项目内拒绝完全相同的组名。
- 一个会话最多属于一个组；未归组会话在默认列表中显示。创建分组不创建本地或远端目录。
- Select 进入多选模式，可将所选会话移入组或移出组；显示选择数量。保留现有单会话删除入口与保护语义，本次不增加批量永久删除。
- 分组可展开/折叠。删除分组只解除归组，保留会话、消息和运行记录。
- 筛选支持标题关键字、已有会话状态和所属分组；支持最近更新/最早创建排序。没有匹配结果时提供清除筛选。
- 默认以更新时间降序，按本地日期显示今天、昨天、近 7 天、更早。非法日期稳定归入更早；时间边界用固定时钟测试。
- 新建项目内 `conversation_groups` 和 `conversation_group_members` 表，不借用带 relative_path 的 `folders` 表。Store 事务验证组与全部会话属于同一项目，跨项目或不存在的成员使整次移动失败。
- 项目、会话删除时按现有所有权清理成员关系；所有迁移可重复执行。界面以成功保存的结果为准，失败时保留原列表并允许重试。
- 创建分组、稿件、收藏及保存稿件版本使用稳定请求 ID；响应丢失后以同一 ID 查询或重试。宿主返回已提交结果，不因重试重复创建；相同 ID 的不同请求内容应报冲突。

## 文件

本地和 SSH 文件在界面上明确区分。未绑定 SSH 时仍可浏览本地项目文件；远端失联显示错误而非空目录。继续使用现有路径限制、预览支持类型和显式上传/下载流程。

打开文件入口只读取列表。不会后台同步大文件，不把远端路径当本地路径打开，不因浏览操作安装依赖或启动计算。现有列表的数量和深度限制必须反映在提示中。

## 研究历程

增加一个只读项目级查询，把 ScientificStateV4 中的数据集、分析、产物、证据及 provenance 和现有 Agent V4 运行摘要投影为可浏览的研究过程。

- 页面提供时间线和类别/状态过滤，展示真实时间、类型、摘要和可证明的来源会话/运行标识。运行时间取持久化事件时间，不能从没有时间字段的运行记录臆造。
- 详情展示已保存的输入/输出关系、执行上下文、校验和、验证问题和证据引用；支持跳回存在的来源会话。
- 同一运行和分析使用稳定 ID 关联；区分 Agent 运行状态、分析状态、工具返回状态和证据有效性，不以其中一种代替另一种。
- 未执行代码、未确认派发、失败和失效证据均按原记录标明；不依据 UI 展示推断科研成功或远端作业已取消。
- 不展示凭据或原始进程身份字符串；只返回视图需要的字段。列表有明确 limit/cursor，详情按需加载，避免一次拉取项目全部原始事件。
- 缺失 ScientificStateV4 的旧项目仍可显示已有运行和旧产物，并标明来源类型；不可把两套 ID 静默合并。
- 来源关联允许缺失：DatasetRecordV4 没有运行/会话 ID，EvidenceRecordV4 的 source_call_id 也不保证跨运行唯一。无法唯一确定时显示“来源未记录”，不按时间邻近或裸 call ID 猜测。

## 发表工作区

提供项目内稿件列表、创建、重命名、Markdown 编辑、保存、历史版本查看及导出 Markdown，形成可用的稿件准备流程。

- 每次保存生成不可改写的版本，记录标题、正文、显式选择的证据引用快照、时间和内容 SHA-256。保存采用预期版本检查；版本冲突提示重新加载，不能覆盖其他窗口的新版本。
- 重命名随正文一起保存为新版本；版本查看、恢复及导出均使用该版本的标题，不以稿件当前名称替换历史标题。
- 复用现有 publications/publication_revisions 表。正文及引用放入有 schema_version 的内容结构；旧版本的纯文本 content 按旧稿件只读展示，未知结构保留原文并提示不能解析，不覆盖或丢弃。新保存生成独立新版本，不启用与本次行为无关的预留表。
- 用户可从本项目研究历程选择分析、产物、证据或记录作为参考。宿主按 source_kind + ID 校验归属并生成摘要快照，客户端不能提交 verified 标记或任意其他项目来源。
- 引用保留来源 ID、类型、保存时状态与可用校验和；之后来源变化或缺失时明确提示。摘要快照不替代原始执行证据，也不宣称包含源文件字节。
- 版本历史只读。恢复旧稿件通过新建版本完成，不改写旧版本。
- 导出由用户显式选择保存位置，内容为选定已保存版本的 Markdown 与引用清单。取消保存对话框不显示成功，错误可重试。
- 本次不实现投稿服务、冻结批准、证据胶囊或自动重现；界面不提供这些操作或状态。

## 资料库

提供当前安装下跨项目使用的个人收藏：代码片段、对话摘录和产物引用。可搜索标题及已保存文本，按类型和来源项目过滤，查看详情、移除收藏、跳回来源或插入当前会话草稿。

- 从代码单元、消息摘录及研究历程产物详情提供收藏动作。保存操作由宿主验证来源项目及精确消息/产物身份，再生成收藏内容；不接受任意路径读取请求。
- 消息代码和摘录采用 message_id、消息内容摘要和选中范围定位；运行代码采用 run_id、事件序号/摘要及 call_id 定位。宿主从持久记录重建并验证文本，不信任前端临时单元 ID 或裸 call_id。
- 代码和摘录保存不可改写的文本快照及 SHA-256，并记录来源项目/会话名称与 ID；删除来源不删除收藏。来源已不存在时仍可查看快照，跳转动作明确不可用。
- 产物收藏保存路径、位置、类型、大小、校验和及来源快照，位置固定为来源分析的 backend 身份及当时可证明的位置元数据。界面明确“产物引用”；源文件移除后不声称仍能预览。远端产物保持引用，不自动传输数据。
- 项目改绑 SSH 或更换目录后，不根据新配置读取同名文件。无法确认原位置时只展示引用；来源删除后不能利用残留路径绕过当前项目授权读取文件。
- 预览矩阵明确为现有受控本地文本与 SSH 图片支持的类型，其他类型提供元数据详情，不展示虚假的预览按钮。本次不承诺已有本地图片预览接口。预览前验证来源位置与当前项目授权仍匹配，并核对可支持文件的校验和；不一致时显示来源已变化，不能当作原收藏内容。
- 插入会话只填入草稿，保留已有输入；用户发送后才进入 Agent 流程。移除收藏不删除来源文件和原始消息。
- 新增专用收藏表，来源 ID 不使用会随源项目删除的级联外键。列表返回有界摘要，详情按需加载全文；限制文本大小并报告超限错误。
- 此版保存文本快照与产物元数据，不复制整张图像或大型文件；全局图像字节副本和收藏代码版本编辑可作为后续独立扩展。

## 实现边界

- 持久化、所有权验证与事务：`crates/omicsops-store/`；需要新增的方法放职责清楚的导航/发表/收藏模块，不因文件长度进行无关重构。
- 纯数据 UI 契约：`crates/omicsops-dto/`，由 `src-tauri/src/dto.rs` 重导出，并更新 `src-tauri/src/dto_contract_tests.rs`。
- 宿主组合：在 `src-tauri/src/` 新增相关命令模块，在 `lib.rs` 注册。复用现有 AppState、Store、受控文件读取、脱敏和导出路径。
- 前端：左导航组件、研究历程页面、发表页面和资料库页面放 `src/features/workspace/`；`DesktopApp`/`WorkspaceShell` 负责项目和会话导航。类型、API 包装使用现有统一入口与模式。
- 保持本地与 SSH 边界、凭据管理、审批和冻结运行计划不变。资料组织操作不调用模型、不启动 shell、不扩大 MCP 权限。
- 消息、代码、稿件及引用快照在保存、导出和插入草稿前经过现有脱敏边界。文本 SHA-256 针对实际保存的脱敏文本计算，与原文件校验和分别记录和标注；不能声称脱敏快照与原文相同。

## 验证与交付

确定性测试至少覆盖：

1. 分组创建/重命名/删除、批量移动原子性、跨项目拒绝、源会话删除清理、数据库重开与幂等迁移。
2. 研究历程同时包含 V4 与明确标识的旧记录；状态映射、失效证据、来源详情和分页；不把生成代码或不确定派发标为成功。
3. 稿件保存/历史/恢复、版本冲突、跨项目引用拒绝、来源缺失、导出选择/取消/失败和重启恢复。
4. 收藏快照在源删除后仍可读、重复收藏处理、精确消息/事件定位、搜索、移除不影响源、来源改变提示、SSH 改绑拒绝错误读取、路径和大小限制、脱敏后摘要。
5. UI 导航、会话草稿保留、日期分桶、筛选、多选、快捷键单次触发；新菜单/对话框打开后立即 Escape，仅关闭视觉顶层。
6. 切换项目时在途请求不污染新页面，失败重试不重复创建对象；中英文及深浅主题。

先运行邻近测试，交付前运行 `cargo test --workspace`、`npm test`、`npm run build`。由于新增桌面命令与组合，再运行 `npm run build:desktop`。锁文件如发生变化，增加 `npm ci`。记录实际通过、失败和 ignored 数量，不能把 ignored 用例计为通过。

手工 Windows smoke：新建两个会话和分组、归组、筛选、切换/折叠导航、重启恢复；检查本地文件与 SSH 未连接提示；打开具有实际 V4 数据的研究历程；保存两个稿件版本、重开、导出；收藏片段/产物引用、插入草稿、删除来源后核查快照；逐层 Escape。

本次不改变真实 Agent/SSH 执行。真实模型、SSH、R、Micromamba 和 PBMC 验收如未执行须如实标记，不能以构建或模拟测试代替。
