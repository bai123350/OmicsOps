# Agent V4 模型轮次超时边界

> 日期：2026-09-21
> 状态：已实现

Agent V4 对每次模型轮次保留一个绝对 180 秒上限，与内置模型适配器的 HTTP
请求总上限一致。该上限覆盖一次逻辑流请求及其适配器内部重试或 fallback；流式
文本、工具参数、usage 或推理活动不会把总上限无限延后。静默或持续活动但始终
不结束的请求仍会在总上限处失败。

这个边界只约束模型请求，不改变工具执行、远端作业或 shell 的超时。取消和新
guidance 仍以 50 毫秒轮询边界中断等待；模型重试数、Agent iteration、工具调用
预算和 delegated budget 继续独立生效。模型超时只终止当前模型等待，不把已派
发的远端计算记为已取消，也不会自动重放副作用工具。

调用方仍可为确定性测试或特殊的有界子流程显式设置更短的
`model_attempt_timeout`。真实模型 acceptance 使用生产默认值，避免由测试专属
覆盖掩盖桌面组合中的配置差异。
