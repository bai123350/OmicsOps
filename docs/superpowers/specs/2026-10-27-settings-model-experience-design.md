# 设置与模型配置体验改进

## 目标与参考

改善设置页视觉层级，以及新增、编辑、查询模型的操作路径。参考
[wisp-science 设置界面](https://github.com/xuzhougeng/wisp-science/blob/main/ui/src/settings_view.rs)
和其 `ui/src/styles/settings.css` 的分组侧栏、内容宽度、可读字号与高级参数折叠方式。
本次采用原项目的 React 19 / TypeScript / CSS 与现有 Tauri 命令，不复制其 Rust UI 实现。

## 方案

- 仅调整颜色与间距成本较低，但不能解决模型配置埋在 18 个提供方之后的问题。
- 全面改成提供方下多模型的数据结构，会涉及持久化与凭据边界，超出本次界面改善范围。
- 本次选择：统一设置框架，已保存模型优先，新增提供方用紧凑可搜索目录，连接信息和高级参数分层。由实现者根据现有结构作此选择。

## 可观察行为

- 返回工作区、设置标题和搜索集中在侧栏；内容区使用一致的留白、标题、控件和焦点样式，支持现有深浅主题。
- 已保存模型先于新增提供方展示；清楚区分“已配置”与真实测试结果。
- 提供方目录支持搜索及 API / 订阅 / 本地分类，并保留全部现有预设。
- 编辑时优先显示名称、完整模型 ID、Base URL 和密钥；预算、推理、Fast、目录能力刷新与子 Agent 选项收进高级配置。
- 新密钥可显隐，编辑时明确提示留空保留已有密钥，绝不读取或回填已存密钥。
- 保存有进行中、失败和成功反馈；旧保存请求不得覆盖后来打开的表单。保存配置后旧测试/查询结果失效。
- 已保存配置的模型查询结果可筛选，选择保留完整模型 ID；新配置继续先保存再查询。
- Escape 使用现有窗口级堆栈，立即按键只关闭当前顶层编辑/确认界面。

## 边界

不新增依赖、数据库表、DTO 或后端命令。凭据继续通过宿主写系统 keyring；不写本地存储、日志或导出。目录能力保持精确协议、HTTPS host/端口及完整模型 ID 匹配。保留原预算 dirty、目录刷新、订阅授权和子 Agent 冻结语义。模型或外部服务可能接收提示词、结果和元数据的提示继续显示。

## 验证

扩充设置页自动化测试，保留所有既有模型契约断言；覆盖搜索/分类、折叠配置、密钥显隐、保存并发、查询筛选、Escape 与中英文。运行 `npm run build`、`cargo test --workspace`、`npm test`。本次不改 Tauri 配置、桌面组合或安装资源。浏览器使用模拟配置检查默认 1100×680 与最小 900×560 尺寸、暗色主题及常规设置。真实模型/SSH/订阅登录验收不属于模拟测试结果。
