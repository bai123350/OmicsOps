# 主对话中的远端项目图片

## 问题与范围

助手消息中的 Markdown 图片，例如
`![UMAP](results/hcc/figures/umap_stage3_umap_final.png)`，此前直接成为
WebView 的 `<img src="results/…">`。浏览器因此向应用自身的资源地址请求
图片，无法读取 SSH 项目中已经存在的结果文件。文件存在和运行成功不能使
浏览器相对 URL 自动获得项目或 SSH 上下文。

本次修复在主对话 Markdown 图片渲染处接入已有的
`previewProjectImage(projectId, relativePath)` / `preview_project_image`。
图片在对应消息中显示；可继续使用原有的文件与产物预览入口。
不新增原生命令、DTO、数据库表、同步任务或图片文件副本。

## 可观察行为

- 当前项目具有 SSH 连接与远端根目录时，消息中的安全项目图片路径通过宿主
  读取，并使用宿主返回的图片 `data_url` 显示，保留 Markdown 的替代文本。
- 图片读取期间显示加载状态。读取失败或图片无法解码时显示明确的失败状态，
  不向用户展示原始 SSH 错误、服务器诊断或凭据；允许用户手动重试。
- 消息重绘和同一作用域内的重复引用不应因父组件新建回调对象而不断发起读取。
- 项目、对话、连接或远端根目录变化后，旧作用域的图片结果不能进入新作用域。
  图片来源变化或组件卸载后返回的旧请求也不能覆盖当前显示。

## 路径与来源

图片解析只将受支持的项目文件路径交给已有宿主命令。支持项目相对路径，
以及明确位于所配置远端根目录下的绝对路径和无远端主机部分的 `file:///`
路径。绝对路径须按路径组件边界去除根目录前缀；例如根目录为 `/work/study`
时，`/work/study-old/figure.png` 不能匹配。宿主最终只接收项目相对路径。

在任何可能消除路径片段的 URL 或路径规范化前，拒绝父目录穿越。编码后的
路径也须接受同样校验，拒绝控制字符、Windows 盘符与 UNC 路径、带主机的
文件 URL，以及清理后指向 `.omicsops` 的内部元数据路径。不以图片扩展名
作为项目权限或内容真实性的证明。

HTTP(S) 与其他外部来源不会被解释为 SSH 项目路径。现有 WebView CSP 仍为
`img-src 'self' data:`；此次修复不扩大外部网络图片访问权限。

现有命令只读取项目绑定的 SSH 根目录，不支持本地文件来源选择。此次修复
沿用该含义：相对路径在 SSH 已绑定项目中指向远端项目；不根据文件是否存在
在本地与 SSH 之间回退。没有 SSH 绑定时，不调用此远端图片命令。本地图片
预览、运行产物来源绑定和历史项目绑定快照不属于此次变更。

配置的远端根目录与服务器 canonical 根目录可能不同。前端只转换能明确归属
配置根目录的绝对路径，不猜测目录别名；项目相对路径仍由宿主解析到实际根目录。

## 宿主与数据边界

继续复用 `src-tauri/src/sync_commands.rs` 中的现有处理：

1. 从项目读取连接与根目录，检查已信任的 SSH 主机，凭据沿用现有 keyring 路径。
2. 校验项目相对路径，解析远端根目录和文件路径，要求普通文件及解析后的根目录
   包含关系，并保留原有末级符号链接拒绝规则。
3. 检查文件大小，并通过 SFTP 最多读取 20 MiB 加一个探测字节，超限拒绝。
4. 比对远端 SHA-256 与读取内容的 SHA-256，按扩展名和文件签名接受 PNG、
   JPEG、GIF、WebP 或 BMP，然后返回图片 data URL。

图片 bytes 经 SSH 传到桌面用于显示；这属于按需预览，不产生持久化同步记录，
也不自动将图片 bytes 加入模型上下文。现有消息文本和其他工具数据仍遵循原有
传输流程，不能据此声称所有科研数据永远不离开本机。

不改变 Agent 审批、冻结执行计划、作业派发或恢复语义。忽略过期结果不等于
已取消后端 SSH 操作。当前图片命令的既有连接、超时和路径检查到文件读取之间
的竞态边界保持不变；此次 UI 接线不宣称提供原子文件快照。
