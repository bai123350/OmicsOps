## 问题与边界

OpenCode Go 的 deepseek-v4.1-flash 对话在宿主构造上下文时停止，错误为
`266925 > 262144`。只读检查确认单份科研状态为 131,813 字节，同时存在于当前状态
和历史检查点中；即使近期步骤已经清空，重复状态仍然超过宿主字节预算。这不是
提供方返回的 token 上限错误，界面最近一次请求的使用率也不代表本次候选已发送。

修复提交 `fd3cca7`，独立格式提交 `4fff71d`。模型检查点仅保留历史状态元数据，
顶层呈现当前状态；单份状态仍放不下时，先归档并持久化完整检查点，再发送带真实
事件引用的记录目录，使用已有读取工具的 scientific_state 字段分页获取原文。
完整请求仍须通过宿主和模型适配器预算校验。重建上下文复用相同快照，状态变化
生成新引用；近期工具结果按精简后的实际请求预算裁剪。

没有改变 SQLite 模式、冻结计划、模型目录、审批或凭据存储。原始事件、完整状态
及归档证据保留。读取继续限定当前 run/project/conversation 并校验事件哈希；
没有可用读取工具、归档失败或不可缩减内容仍超预算时保持停止语义。
